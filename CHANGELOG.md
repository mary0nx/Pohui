# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer.

## [0.4.0] — 2026-10-25

### Добавлено
- **Apple Pay → расходы** (Профиль → Apple Pay): личный ключ для автоматизации «Транзакция»
  в Быстрых командах iPhone (iOS 17+). Каждая оплата картой из Wallet приходит на
  `POST /api/v1/hooks/apple-pay` с суммой, продавцом, картой и местом и записывается
  расходом (минус — возврат) в выбранный счёт; категория — как в прошлый раз у этого
  продавца или по названию магазина (Biedronka → Продукты, Orlen → Транспорт…); оплата в
  другой валюте — в счёт этой валюты; повтор в ту же минуту не дублируется. Ответ — текст
  для уведомления на iPhone. Ключ хранится только в виде SHA-256, показывается один раз,
  может быть прислан в чат с ботом; новый ключ заменяет старый (миграция d91f4b6a2c58).
- Мастер рабочего графика: первый день шаблона обязателен, предпросмотр ближайших дней.

## [0.3.0] — 2026-10-24

### Добавлено
- **Рабочий график** (Календарь → кнопка с портфелем): шаблон смен (Д — день, Н — ночь,
  В — выходной; готовые варианты, напр. «2 дня · 2 ночи · 4 выходных»), первый день цикла и
  период — график заполняется на полгода; отдельные дни правятся касанием (дневная → ночная →
  выходной). В месяце дневные смены — жёлтые, ночные — красные. Смены личные (`work_shifts`,
  миграция c3e8a5f20d71, API `/calendar/shifts`).
- **Праздники Польши** в календаре (считаются на устройстве): выходные праздники (★, с
  Wigilia с 2025 г.), торговые воскресенья (🛒, по правилам с 2025 г. — 3 в декабре),
  великие католические (✝) и православные (☦) праздники; каждый слой включается отдельно.

### Изменено
- Календарь открывается в режиме «Месяц» (выбор режима запоминается).

## [0.2.0] — 2026-10-24

### Добавлено
- **Покупки по дням**: в списке покупок режим «По дням» — неделя (Пн–Вс) с «+» у каждого дня,
  товары с днём покупки (`planned_for`), выбор дня в карточке товара. В 9:00 этого дня (часовой
  пояс семьи) всем участникам приходит «🛒 Купить сегодня» (новая категория уведомлений
  «Покупки на сегодня», её можно выключить).
- **Задачи по дням**: в задачах режим «Неделя» с «+» у каждого дня (срок подставляется). В 9:00
  каждому участнику приходит «📝 Задачи на сегодня» — его задачи и общие, личные только автору.
- **Цветовые палитры**: Профиль → Приложение → Цвет (Мята, Океан, Лаванда, Роза, Закат, Лес,
  Графит) для светлой и тёмной темы; выбор темы и цвета синхронизируется между устройствами
  через Telegram CloudStorage.

### Изменено
- AI-ассистент скрыт, пока на сервере не заданы `OPENAI_API_KEY` и `AI_MODEL`: нет кнопки,
  подсказок и пунктов настроек, `/assistant` ведёт на главную; бот на свободный текст отвечает
  ссылкой на приложение. Код ассистента сохранён — он вернётся после добавления ключа.

## [0.1.2] — 2026-10-24

### Исправлено
- Сборка на Cloudflare Pages без `VITE_API_URL` отправляла запросы API на сам `pages.dev`.
  Теперь такая сборка (`CF_PAGES=1`) сразу показывает «Сервер Family OS не подключён» с
  инструкцией, а адрес `*.pages.dev` в `VITE_API_URL` отклоняется.

### Добавлено
- Режим одного процесса для бесплатного хостинга: `EMBEDDED_WORKER=true` (фоновые задачи в
  процессе API), `EMBEDDED_BOT=true` (вебхук Telegram `/tg/webhook` в API с проверкой секрета и
  повтором регистрации), `backend/scripts/start-single-service.sh`.
- `render.yaml` (Render Blueprint, бесплатный план) и `docs/RENDER_SUPABASE.md` — пошаговое
  бесплатное размещение backend.
- Строки подключения хостингов PostgreSQL (`postgresql://...?sslmode=require`, пулеры Neon и
  Supabase) принимаются без ручной правки; `DB_MAX_OVERFLOW`.
- `python -m app.db.lockdown`: отзыв доступа Data API Supabase (`anon`, `authenticated`) к
  таблицам Family OS.
- `/health/ready` называет проблему базы (`problem`: неверный пароль, пользователь, адрес,
  имя базы, нет миграций) без раскрытия строки подключения; в режиме одного процесса сервер
  стартует и при ошибке базы (3 попытки миграций), чтобы причину было видно без логов хостинга.
- `DATABASE_PASSWORD`: пароль базы отдельно от строки подключения (любые символы, кодируется
  автоматически); строка Supabase с `[YOUR-PASSWORD]` принимается как есть.
- `CORS_ORIGIN_REGEX` для адресов отдельных сборок Pages; `RENDER_EXTERNAL_URL` заполняет
  `BACKEND_URL`/`TELEGRAM_WEBHOOK_URL`; секрет вебхука выводится из `APP_SECRET_KEY`, если не задан.

## [0.1.1] — 2026-10-24

### Исправлено
- Frontend на статическом хостинге без backend (Cloudflare Pages) падал с
  `undefined is not an object (evaluating 'V.dev_auth')`: Pages отдаёт `index.html` со
  статусом 200 на `/api/*`, а клиент API возвращал `undefined` вместо ошибки. Теперь HTML,
  пустой и некорректный ответ дают понятную ошибку, ответы `/meta`, `/me`, `/auth/*`
  проверяются по схеме, а при недоступном сервере показывается экран «Сервер Family OS
  недоступен» с адресом API и кнопкой повтора.

### Добавлено
- `VITE_API_URL` с проверкой формата для размещения frontend отдельно от API;
  `frontend/.env.example`, `frontend/public/_headers` для Cloudflare Pages.
- Тесты: ответ SPA-фолбэка, пустой/битый JSON, нарушение контракта `/meta`, вход внутри
  Telegram; backend-тесты контракта `/meta`, JSON 404 для `/api/*`, CORS.
- `docs/CLOUDFLARE_PAGES.md`: настройки Pages и варианты размещения backend.

## [0.1.0] — 2026-10-24

Первая рабочая версия.

### Добавлено
- Telegram-авторизация по initData, серверные сессии, явный dev-вход только для разработки.
- Семейные пространства, роли, приглашения, выход/удаление участников, удаление семьи.
- Финансы: счета, категории, операции, переводы, возвраты, сводки, графики, бюджеты,
  регулярные платежи, накопления, импорт CSV, идемпотентное создание операций.
- Календарь с повторениями (с учётом перехода на летнее/зимнее время), RSVP, напоминания.
- Списки покупок с массовым вводом, историей и синхронизацией; домашние задачи.
- Продукты, рецепты, недельное меню и список покупок из меню.
- Совместная жизнь: цели, желания, идеи, журнал, заметки, привычки.
- Документы с безопасной загрузкой и временными ссылками на скачивание.
- Уведомления в Telegram через надёжную очередь в PostgreSQL, тихие часы, настройки категорий.
- AI-ассистент с ограниченным набором инструментов, подтверждениями, памятью и лимитами.
- Telegram-бот: команды, AI-диалог, кнопки подтверждения, webhook/polling.
- Docker Compose, Caddy с HTTPS, скрипты резервного копирования и проверки восстановления, CI.
