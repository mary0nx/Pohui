# Family OS — дизайн-система «Playful Life × Cozy Home»

## Цвета (`frontend/src/styles/index.css`)

| Токен | Светлая | Назначение |
|---|---|---|
| `--cream` / `--bg` | `#FFF7ED` | фон экранов |
| `--surface` / `--surface-2` | `#FFFDF9` / `#FBEEE0` | карточки / подложки, поля |
| `--coral` | `#FF786B` | основное действие (`--accent` по умолчанию), расходы |
| `--mint` | `#9DDCC5` | успех, доходы, выполнено |
| `--lavender` | `#C7B8F5` | события, итоги |
| `--lemon` | `#F8D96D` | задачи, предупреждения, дневные смены |
| `--forest` | `#315B4C` | фокус, успех-текст, бренд |
| `--ink` / `--text` | `#2B2420` | текст |

Яркие цвета — только для действий, прогресса, статусов и выделенных карточек (`<Card tone="mint">`),
крупные поверхности остаются кремовыми. Текст на ярком — `--on-bright` (тёмный). Тёмная тема —
тёплые какао-поверхности (`#1C1714`/`#262019`). Все пары текста ≥ 4.5:1 (проверено axe, WCAG 2 AA).
Фокус клавиатуры — `--focus` (forest / mint), 2.5 px.

## Форма и шрифт
- Шрифт Nunito Variable (кириллица + латиница, локально через `@fontsource-variable/nunito`).
- Радиусы: карточки 22 px, окна 28–32 px, кнопки и переключатели — «пилюли».
- Тени тёплые и мягкие: `--shadow`, `--shadow-lg`.

## Движение
- Анимируются только `transform`/`opacity`; длительности 140–420 мс, `--ease-out` и пружинный `--ease-spring`.
- Экран: `animate-fade-in`; карточки: `.stagger` (первые 8, шаг 40 мс); нажатие: `.press` (scale 0.96).
- Окна и уведомления — анимации входа и выхода (Radix `data-state`).
- Прогресс: `ProgressBar`, `ProgressRing` растут от нуля при появлении; графики recharts — 600–700 мс.
- `CheckCircle` — прорисовка галочки и «поп»; `celebrate()` — небольшие конфетти только за
  достижения (цель накоплена, куплен последний товар, закрыта последняя задача).
- `prefers-reduced-motion: reduce` — все анимации и переходы мгновенные, конфетти и анимации графиков выключены.
