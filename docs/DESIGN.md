# Family OS — дизайн-система «Cozy Home × Playful Life» (v2)

Светлая тема — основная и включается при первом запуске (даже если в Telegram или системе
тёмная). Тёмная — по выбору: Профиль → Приложение → Тема.

## Цвета (`frontend/src/styles/index.css`)

| Токен | Светлая | Назначение |
|---|---|---|
| `--bg` (`--cream`) | `#FFF7ED` | фон экранов |
| `--surface` | `#FFFFFF` | карточки |
| `--surface-2` | `#FBF1E6` | подложки, поля, строки внутри карточек |
| `--mint` | `#D9F0E4` | покупки, доходы, «сделано» |
| `--sage` | `#9FC7AE` | отмеченные галочки, «Вместе», прогресс |
| `--peach` | `#FFE0D2` | расходы, кухня, активная вкладка навигации |
| `--coral` | `#F47F70` | основное действие (`--accent`), уведомления |
| `--lavender` | `#E8DFFD` | события и календарь, документы |
| `--lemon` | `#F8E7A0` | задачи |
| `--text` / `--heading` | `#315B4C` / `#2A4A3E` | основной текст и заголовки (тёмно-зелёный) |
| `--muted` / `--subtle` | `#6E5D52` / `#716157` | вторичный текст (тёплый серо-коричневый) |

У каждого оттенка есть `--*-ink` — тёмный вариант для иконок и подписей на этом оттенке
(`text-mint-ink` на `bg-mint` и т. д.). Текст на коралле — `--accent-fg` (`#3D1C16`).
Все пары текста ≥ 4.5:1 (axe, WCAG 2 AA) на белом, кремовом и всех оттенках.
Тёмная тема — «лесной вечер» (`#16201C` / `#1F2B26`), без коричнево-чёрного фона.

### Акценты разделов
Главная — коралл и персик; финансы — мята/персик/лаванда; календарь и события — лаванда;
покупки — мята; задачи — лимон; кухня — персик; документы — лаванда; «Вместе» — шалфей;
профиль — персик/мята. Визуальный язык общий: белые карточки, мягкие тени, радиус 22 px.

## Иллюстрации (`frontend/src/components/illustrations/Art.tsx`)
Собственные векторные рисунки: дом, растение, календарь, корзина, список дел, копилка,
документы, кастрюля, две кружки, колокольчик, график. Одна толщина линии (2.5), одна
палитра (`--ill-*`, есть вариант для тёмной темы), декоративные (`aria-hidden`).
Используются в приветствии на главной, в заголовках разделов (`<PageHeader art="…">`),
на плитках раздела «Дом» и в пустых состояниях (`<EmptyState art="…" action={…}>`).

## Форма и шрифт
- Шрифт Nunito Variable (кириллица + латиница, локально через `@fontsource-variable/nunito`).
- Радиусы: карточки 22 px, окна 28–32 px, кнопки и переключатели — «пилюли».
- Мягкие тёплые тени (`--shadow`, `--shadow-lg`) вместо рамок.
- Иконки — один набор (lucide), одна толщина линии 1.9 для всех.
- Нижняя навигация — лёгкая плавающая панель с учётом safe area iPhone; содержимое не
  перекрывается (`.pb-nav`).

## Движение (только `transform`/`opacity`, кроме раскрытия блока)
| Что | Где в коде |
|---|---|
| Карточки экрана появляются по очереди со смещением | `.stagger` (шаг 55 мс, первые 8); на главной — только при первом входе за сессию, возврат и фоновое обновление без повторной анимации |
| Иллюстрация «живёт» несколько секунд и замирает | `<Art alive>`: листья покачиваются (`.ill-sway`), сердечко появляется и всплывает (`.ill-heart`), дымок дрейфует (`.ill-smoke`) |
| Суммы мягко проявляются (значение верное с первого кадра, без «пересчёта») | `.num-in` (главная, обзор финансов) |
| Иконка выбранной вкладки пружинит | `.nav-pop` в нижней навигации |
| Переход между разделами (240 мс, сдвиг 8 px) | `.animate-page-in` на `<main>` (AppShell) |
| Переключение вкладок | `.animate-tab-in` (финансы, календарь, задачи, кухня, «Вместе») |
| Раскрытие карточки | `<Collapse>` (`.collapse-panel`, «Последние изменения» на главной) |
| Кольцо бюджета и цели заполняются от нуля | `ProgressRing`, `ProgressBar` |
| Графики строятся | recharts `isAnimationActive` (обзор финансов) |
| Пружинящая галочка | `CheckCircle` (`.animate-check` + прорисовка); `TaskRow` показывает её сразу и обновляет список после анимации |
| Конфетти | `celebrate()`: цель накоплена, куплен последний товар, закрыта последняя задача, серия из 3 дел за 10 минут (`recordTaskDone`) |
| Реакция на нажатие | `.press`: сжатие до 0.96 за 90 мс, пружинный возврат 320 мс |
| Скелетоны загрузки | `Skeleton` (`.skeleton-shimmer`) |
| Окна и уведомления | вход и выход (Radix `data-state`) |

`prefers-reduced-motion: reduce` — все анимации и переходы мгновенные, конфетти и анимации
графиков выключены, задача отмечается без задержки.
