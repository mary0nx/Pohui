# «Мой маршрут» — поездки на трамвае и автобусе во Вроцлаве

## Что умеет

- **Мои места** (`/route/places`): дом, работа и до 10 других мест на человека. Адрес ищется
  с подсказками по официальному справочнику адресов Вроцлава, перед сохранением показываются
  индекс, район, ближайшие остановки с линиями и небольшая схема; по желанию — ссылка на
  OpenStreetMap. Место можно изменить, удалить и показать семье.
- **Карточка на главной**: «Дом → Работа» / «Работа → Дом», лучший вариант сейчас — линия,
  остановка, через сколько выходить, время в пути и пересадки.
- **Варианты** (`/route`): быстрее всего, меньше пересадок, меньше пешком, следующий рейс
  (в режиме «Прибыть к» — «выйти позже всего» и «с запасом»), пешком, если так быстрее.
  Отправление сейчас / в выбранное время / прибытие к времени; на сегодня, завтра,
  послезавтра. Пошаговая схема: пешком до остановки, линия и направление, время отправления,
  число остановок, выход, пересадка с ожиданием, пешком до места; предупреждение о короткой
  пересадке. Избранные маршруты, предпочтение для рекомендации, предел ходьбы, ручное
  обновление, ссылка на ту же поездку в Jakdojade.

## Источники данных

| Источник | Что даёт | Доступ |
|---|---|---|
| «Rozkład jazdy transportu publicznego», Urząd Miejski Wrocławia, open-data.cui.wroclaw.pl | GTFS: остановки, линии, рейсы, календарь (будни, выходные, праздники) | открыто, лицензия CC0 1.0, без ключей |
| «Ewidencja miejscowości, ulic i adresów» (EMUiA), geoportal.wroclaw.pl | 77 тыс. адресов с координатами | открыто, «brak ograniczeń»; копия в `backend/app/modules/transit/data/` |
| Jakdojade REST API (docs.jakdojade.pl/restxml) | маршруты Jakdojade | **только с партнёрскими ключами** |
| Ссылки jakdojade.pl по документированной схеме URL | открыть поездку в Jakdojade | открыто (это просто ссылка на сайт) |

Адрес, который вы набираете, ищется на нашем сервере — сторонние геокодеры его не видят.
В базе адрес и координаты хранятся зашифрованными (AES-GCM, ключ из `APP_SECRET_KEY`).
Адреса передаются только в теле запросов, не в URL, и не пишутся в логи.

## Как обновляется расписание

Раз в час фоновая задача спрашивает у API портала (`api.open-data.cui.wroclaw.pl/od2/6/`)
список файлов. Новый файл скачивается один раз, сверяется по размеру, полностью разбирается
и только после этого сохраняется в базе (без `shapes.txt`). Сломанный файл не заменяет
рабочий. Для каждой даты используется самый новый файл, который её покрывает
(`feed_info`). Если портал не отвечает дольше 72 часов, маршруты показываются с
предупреждением и без отметки «Рекомендуем». Если на дату нет действующего расписания,
маршрут не строится.

## Реальное время

Не подключено. На портале города есть только «Lokalizacja pojazdów» — положения машин,
обновляемые раз в 10 минут, без прогнозов и задержек; выдавать по ним «реальное время»
было бы неправдой. Все времена в приложении помечены «по расписанию». Поля для прогноза и
подтверждения (`time_kind`, `delay_min`) уже есть и заполнятся, когда появится разрешённый
источник.

## Jakdojade: что нужно для подключения API

1. Написать на biuro@jakdojade.pl и получить публичный ключ и секрет (условия индивидуальные).
2. В Render → Environment добавить `JAKDOJADE_API_KEY` и `JAKDOJADE_API_SECRET`.
3. После этого маршруты сначала запрашиваются у Jakdojade (координаты начала и конца
   округляются до ~10 м и уходят в Jakdojade), при сбое — по открытому расписанию.
   Ответ с тестовыми данными (без авторизации) никогда не показывается.

## Ограничения

- Пешие участки оцениваются по прямой × 1,3 со скоростью 4,5 км/ч (отмечено «≈»).
- Поиск — до 3 пересадок и на 3 часа вперёд; рейсы после полуночи учитываются.
- На бесплатном сервере Render после перезапуска расписание загружается в память около
  минуты — в это время показывается «Загружаем расписание».
- Напоминание «пора выходить» пока не сделано: без данных о задержках время выхода
  известно только по расписанию.
- Справочник адресов обновляется командой
  `python backend/scripts/build_addresses.py <gml.zip> [Adresy.zip]`.
