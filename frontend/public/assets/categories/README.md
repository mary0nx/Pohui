# Category illustrations

Original drawings made for Family OS (from the «family-os-polish-merchant-kit»; `grocery-basket`,
`cash` and `bills` redrawn/added in this repository). They are shown for a transaction when the
shop is unknown or has no logo file: `grocery-basket` for groceries, `food`, `transport`, `fuel`,
`electronics`, `health`, `delivery`, `bills` (telecom, utilities, subscriptions), `store` for other
shops, and `transfer`, `topup`, `bank-fee`, `cash` for operations that are not purchases.
