## Ключевые решения
* **Очередь задач в PostgreSQL** вместо Celery: один источник истины для состояния
  уведомлений, транзакционное создание вместе с бизнес-данными, нет отдельного брокера.
  Redis используется только для rate limiting.
* **Bearer-токен** вместо cookie: Telegram Web открывает Mini App во фрейме, где
  сторонние cookie блокируются браузерами.
* **Polling** вместо WebSocket: надёжно в WebView Telegram, достаточно для двух человек.
* **Caddy раздаёт собранную статику** фронтенда — отдельный Node-сервер не нужен.
* **TypeScript 5.9 / Vite 7 / Vitest 3 / React Router 7** — последние версии
  известных стабильных мажорных линеек вместо только что вышедших мажоров.
